# Frontend

React 18 + TypeScript + TailwindCSS + Vite SPA.

## Layout

- `src/api/` — HTTP client and typed endpoint modules
- `src/components/` — Shared UI (`ui/`, `layout/`, `shared/`)
- `src/features/` — Domain feature modules (mirror backend domains)
- `src/providers/` — Auth, tenant, notification context
- `src/routes/` — Route tree and access guards
- `src/lib/` — Pure utilities (formatters, validators, permissions)
- `src/types/` — Global TypeScript interfaces

See [docs/PROJECT_STRUCTURE.md](../docs/PROJECT_STRUCTURE.md) §4.
